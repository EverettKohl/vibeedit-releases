# VibeEdit for Mac

Official release downloads for VibeEdit, a free local media library and companion app for Apple Silicon Macs.

Installers are Developer ID signed by MOMENTA MEDIA INC. and notarized by Apple. Each release includes SHA-256 checksums and exact download metadata.

The 0.1.0 release is an early public preview. Optional local model files download separately. No VibeEdit account or hosted inference subscription is required.

This repository holds distribution artifacts and release notes, not private app data or credentials. Open-source dependency notices, licenses, provenance and applicable build recipes are bundled in the application.
